# Cap Bon Explorer

Portail touristique interactif et responsive dédié à la découverte du Cap Bon.
Projet pédagogique réalisé dans le cadre du module **Développement Web côté client**
(Institut Supérieur des Études Technologiques de Nabeul — A.U. 2026-2027).

> **Démonstration uniquement.** Aucun paiement, aucune donnée envoyée à un serveur,
> aucune réservation réelle n'est effectuée. Toutes les données (activités, tarifs,
> dates, coordonnées) sont fictives.

---

## Aperçu

Cap Bon Explorer permet de :

- parcourir un catalogue de **8 activités** (culture, artisanat, nature, découverte) ;
- **rechercher** une activité par mot-clé et **filtrer** par catégorie en temps réel ;
- consulter la **fiche détaillée** de chaque activité dans une fenêtre modale ;
- consulter l'**agenda** des prochains événements ;
- **simuler une réservation** avec calcul automatique du prix et remise de 10 % dès 4 personnes ;
- lire une **FAQ** et envoyer un message via un formulaire de contact (simulation locale).

Le site est entièrement statique, responsive (mobile / tablette / ordinateur) et
fonctionne sans serveur ni backend.
